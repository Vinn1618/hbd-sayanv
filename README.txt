CARA MENGISI:
1. Taruh foto kalian di folder ini dan beri nama: foto-kita.jpg
2. Taruh lagu di folder ini dan beri nama: lagu.mp3
3. Jangan ubah nama kedua file tersebut.
4. Buka index.html di browser.

CATATAN:
Browser HP biasanya memblokir musik otomatis sebelum ada interaksi.
Karena itu halaman memiliki tombol "Buka suratku". Setelah tombol ditekan,
lagu akan mulai dan akan mengulang otomatis (loop).
